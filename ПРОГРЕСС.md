# Прогресс переноса safronova.com.ua с Vigbo на WordPress

Обновлено: 15.11.2026

## Сроки
- Vigbo оплачен до 01.08.2027. Переезд на свой хостинг — **конец весны 2027**.
- До переезда: готовим, налаживаем и улучшаем сайт на тестовом WordPress.
- Резервные копии: GitHub `ilchenko82/safronova-wp` + папка `G:\работа\safronova`
  (там же `backup/safronova-wp.bundle` — вся история изменений одним файлом).

## Готово
- Тема `safronova` — дизайн 1:1 с Vigbo: шапка с логотипом и меню, слайд-шоу на главной,
  галереи с просмотром на весь экран, блог, форма заявок, подвал, мобильное меню.
- Перенесено: 9 основных страниц, 10 записей блога, 6 скрытых страниц (без пунктов меню,
  как на Vigbo), 386 фото, шрифты, логотип, SEO-заголовки и описания, Facebook Pixel.
- Адреса страниц такие же, как на Vigbo (`/pregnancy`, `/blog/...` и т. д.) — ссылки из Google не сломаются.
- Админка в стиле Vigbo (можно переключить на обычный WordPress):
  - вкладки САЙТ · ОФОРМЛЕНИЕ · НАСТРОЙКИ · СТАТИСТИКА, «Заявки», «Открыть сайт»;
  - «Сайт» — дерево страниц: перетаскивание, переключатель «В меню», подписи, автосохранение;
  - редактор страниц с нижней панелью виджетов: Заголовок, Текст, Цитата, Аккордеон,
    Фотография, Галерея, Плитка фото, Видео, Кнопка, Форма, Колонки, Отступ, Разделитель,
    Соц. иконки, Встроенный код, Готовые блоки;
  - «Оформление» — логотип, иконка сайта, стили, подвал, шаблоны;
  - «Настройки» — название, e-mail для заявок, Pixel, Google Analytics, код в &lt;head&gt;;
  - «Статистика» — просмотры по дням, популярные страницы, источники (без cookies);
  - на телефоне — нижняя панель вкладок.
- Тестовый сайт: https://safronova.s3-tastewp.com (TasteWP, живёт ~до 21.11.2026).

2. Выбрать постоянный хостинг (украинский, с PHP 8.x, бэкапами, SSL).

4. Перед переездом (конец весны): свежий снимок контента с Vigbo, если что-то менялось,
   повторный импорт, перенос домена, проверка всех страниц, Google Search Console.

## Как восстановить из резервной копии
- С GitHub: `git clone https://github.com/ilchenko82/safronova-wp`.
- Из файла: `git clone backup\safronova-wp.bundle safronova-wp`.
- Готовые к установке архивы: `safronova-theme.zip`, `safronova-migration.zip`
  (WordPress → Внешний вид → Темы → Загрузить / Плагины → Добавить → Загрузить).
  Подробности — в `ИНСТРУКЦИЯ.md`.
