# Перенос сайта safronova.com.ua с Vigbo на WordPress

Что лежит в папке:

| Файл / папка | Что это |
|---|---|
| `safronova-theme.zip` | Тема WordPress «Safronova» — внешний вид сайта 1-в-1 как на Vigbo |
| `safronova-migration.zip` | Плагин-импортёр — переносит весь контент и фото одной кнопкой |
| `wp-content\` | То же самое в виде папок (для загрузки по FTP) |
| `download-assets.ps1` + `media-list.txt` | Скрипт резервного скачивания всех фото, шрифтов и логотипа к вам на компьютер |
| `_work\` | Рабочие файлы (снимок старого сайта, конвертер). Для установки не нужны, но удалять не надо — это архив |

---

## Шаг 0. Резервная копия фото (рекомендую сделать сразу)

Пока Vigbo работает, скачайте все фото себе:

1. Правый клик по `download-assets.ps1` → **«Выполнить с помощью PowerShell»**.
2. Скрипт скачает 309 фото в `wp-content\plugins\safronova-migration\media\`, шрифты и логотип — в папку темы. Займёт 5–15 минут.
3. Если Windows не даёт запустить скрипт: откройте PowerShell в этой папке и выполните
   `powershell -ExecutionPolicy Bypass -File .\download-assets.ps1`

Теперь у вас есть полная копия, даже если Vigbo отключат.

## Шаг 1. Хостинг и WordPress

Нужно: **WordPress 6.6+**, **PHP 7.4+** (лучше 8.x), расширения PHP `curl` и `gd` (или `imagick`) — есть почти у любого хостинга.
Установите чистый WordPress (у большинства хостингов это кнопка «Установить WordPress» в панели). Язык можно выбрать любой.

## Шаг 2. Установить тему и плагин

**Вариант А — через админку (проще):**
1. *Внешний вид → Темы → Добавить → Загрузить тему* → `safronova-theme.zip` → Установить → **Активировать**.
2. *Плагины → Добавить новый → Загрузить плагин* → `safronova-migration.zip` → Установить → **Активировать**.

**Вариант Б — по FTP (если делали Шаг 0 — фото загрузятся с вашей копии, без Vigbo):**
1. Скопируйте папку `wp-content` из этой папки поверх `wp-content` на хостинге.
2. В админке активируйте тему «Safronova» и плагин «Safronova — перенос с Vigbo».

## Шаг 3. Перенос

1. *Инструменты → Перенос с Vigbo* → кнопка **«Запустить перенос»**.
2. Не закрывайте вкладку, пока полоса не дойдёт до конца (5–15 минут). В журнале видно каждое фото.
3. В конце должно появиться: **«Ссылок на Vigbo не осталось — сайт полностью независим»**.
   Если какие-то фото не скачались — просто нажмите кнопку ещё раз, докачаются только недостающие.

Что делает перенос:
- 9 страниц и 10 записей блога **с теми же адресами**: `/pregnancy`, `/mothersandkids`, `/podvodnye-fotosessii`, `/blog`, `/blog/katerina`, `/tseny-new`, `/faq`, `/reviews`, `/contacts` — ссылки из Google и Instagram продолжат работать;
- SEO-заголовки и описания каждой страницы — как были;
- меню: **ПОРТФОЛІО** (с подменю) | **БЛОГ** | **ЦІНИ** — логотип — **ПИТАННЯ/ВІДПОВІДЬ** | **ВІДГУКИ** | **КОНТАКТИ**;
- все фото — в медиатеку WordPress, обложки записей блога, логотип, шрифты;
- письма с формы на странице «Контакти» — на **info.elenasafronova@gmail.com**.

## Шаг 4. Проверка

Откройте сайт и пройдитесь: главная (слайдер), три портфолио (клик по фото — просмотр на весь экран со стрелками), блог (2 страницы), цены, вопросы, отзывы, контакты. Проверьте на телефоне — меню-«бургер».

**Отправьте себе тестовое сообщение с формы.** Если письмо не пришло — на хостинге не настроена почта; поставьте плагин **WP Mail SMTP** и подключите в нём Gmail. Это частая история для любого WordPress.

После проверки плагин-импортёр можно **деактивировать и удалить** — на сайте всё останется.

## Шаг 5. Перенос домена

Когда новый сайт проверен — в панели регистратора домена `safronova.com.ua` смените DNS (или A-запись) на хостинг. Если до этого сайт открывался по временному адресу — после смены домена в *Настройки → Общие* поставьте `https://safronova.com.ua`. Затем отключите сайт на Vigbo.

## Как потом редактировать

- **Тексты, цены, фото на страницах** — *Страницы → нужная страница → Изменить*. Всё разложено по блокам: тексты, картинки, колонки, галереи.
- **Новая запись в блог** — *Записи → Добавить*. Обязательно задайте **«Изображение записи»** (обложка в ленте блога, вертикальная 2:3).
- **Галерея портфолио** — на странице выделите блок «Галерея» → добавляйте/удаляйте/перетаскивайте фото. Просмотр на весь экран включится сам.
- **Слайдер на главной** — *Страницы → Головна* → блок «Галерея»: какие фото в нём, те и крутятся.
- **Меню** — *Внешний вид → Меню* (меню слева и справа от логотипа).
- **SEO-заголовок и описание** — внизу редактора каждой страницы/записи, блок «SEO».
- **Адрес для писем с формы** — *Настройки → Общие → «E-mail для формы обратной связи»*.

## Чем новый сайт отличается от старого (сознательно)

- Убрана подпись «сайт от vigbo» в подвале.
- Фото отдаются в нужном размере под экран (на телефоне — меньше), сайт грузится быстрее.
- На старом сайте ссылки «< БЕРЕМЕННЫЕ» и «LOVE STORY >» внизу страницы «Фотосесія з малюком» вели на несуществующие страницы (ошибка 404). Перенесены как есть — можно удалить или поменять в редакторе страницы.
- Лайки-сердечки под записями блога (были видны только на телефоне и везде показывали 0) не переносились.

Если что-то сломалось (белый экран, ошибка) — пришлите мне текст ошибки или файл `wp-content/debug.log`, разберёмся.
