# safronova-wp

Перенос сайта фотографа **Елены Сафроновой** — [safronova.com.ua](https://safronova.com.ua) — с конструктора Vigbo на самостоятельный **WordPress**. Внешний вид и функции — как на прежнем сайте, без привязки к Vigbo.

## ▶ Тест в браузере (без хостинга)

**[Открыть тестовый сайт в WordPress Playground](https://playground.wordpress.net/?blueprint-url=https://raw.githubusercontent.com/ilchenko82/safronova-wp/main/blueprint.json)**

WordPress запускается прямо во вкладке браузера (10–30 секунд), ставит тему, плагин и импортирует весь контент. Админка: `/wp-admin`, логин `admin`, пароль `password`. Всё живёт только в вашей вкладке и исчезает после её закрытия.

> В тестовой версии фото для скорости показываются прямо с серверов Vigbo. На настоящем хостинге плагин-импортёр скачивает все 309 фото в медиатеку WordPress (см. [ИНСТРУКЦИЯ.md](ИНСТРУКЦИЯ.md)).

## Что внутри

| Путь | Что это |
|---|---|
| `wp-content/themes/safronova/` | Блочная тема WordPress: шапка с логотипом по центру и разделённым меню, подменю «Портфоліо», мобильное меню, слайдер на главной, галереи с просмотром на весь экран, лента блога 3 в ряд, форма обратной связи, SEO |
| `wp-content/plugins/safronova-migration/` | Плагин-импортёр (Инструменты → Перенос с Vigbo): 9 страниц, 10 записей блога, меню, SEO-заголовки, фото в медиатеку, логотип, шрифты. Адреса страниц как на Vigbo |
| `download-assets.ps1`, `media-list.txt` | Скрипт для Windows: резервное скачивание всех фото, шрифтов и логотипа с Vigbo |
| `blueprint.json` | Сценарий для WordPress Playground (тестовая ссылка выше) |
| `tools/` | Снимок контента старого сайта (`data/site.json`) и конвертер Vigbo → блоки WordPress (`convert.py`) |
| `ИНСТРУКЦИЯ.md` | Пошаговая установка на хостинг |

## Установка на хостинг — кратко

1. Чистый WordPress 6.6+, PHP 7.4+.
2. Установить и активировать тему `safronova` и плагин `safronova-migration` (папки из `wp-content/` — по FTP, или zip-архивы этих папок через админку).
3. **Инструменты → Перенос с Vigbo → «Запустить перенос»**.

Подробно — в [ИНСТРУКЦИЯ.md](ИНСТРУКЦИЯ.md).

## Пересобрать контент

```bash
python3 tools/convert.py   # tools/data/site.json -> wp-content/plugins/safronova-migration/data/content.json
```
(пути в скрипте рассчитаны на рабочую папку; при необходимости поправьте `ROOT`)
